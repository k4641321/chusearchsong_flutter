# 所有成绩查看
![](image/屏幕截图%202026-08-19%20182254.png)
> [!WARNING]
> 此功能需要配置落雪Token

> ~~从ChiffonMai那抄过来的ui~~

最上面会显示当前游玩的总谱面数，SSS+与SSS的成绩数量，FC、AJ、AJC的数量  
  
支持按 Rating，定数，分数，超越之力排序  
按版本、定数、难度、分数、连击状态进行筛选  
点击歌曲可进入歌曲详情页  
不同评级显示的颜色也不一样：
* SSS、SSS+ 紫
* S~SS+ 粉
* A~AAA 橙
* B~BBB 蓝
* C 绿
* D 灰
