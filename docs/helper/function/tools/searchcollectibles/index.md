## 搜索
目前搜索支持：落雪id，关键字 进行搜索，支持按类别筛选  
搜索结果会以 ***落雪id - 名称 - 类别***进行显示
点击结果可进入收藏品详情页
## 收藏品详情页
收藏品详情页会显示一下内容：
- 收藏品图片（大部分称号除外
- 落雪id
- 收藏品名称
- 描述
- 颜色
- 达成条件（如果有
- 关联曲目
- 完成状态跟进
> [!WARNING] 
> 使用**完成状态跟进**前请配置好落雪token

## 翻译功能
本软件翻译功能使用的是腾讯TMT（机器翻译），可支持**翻译标题**和**翻译描述**
> [!WARNING] 
> 使用**翻译功能**前请配置好腾讯TMT的相关配置，可以免费申请，每个月的额度够用了

## 隐藏操作
**长按名称**可以进行复制，**长按描述**可以进行复制
