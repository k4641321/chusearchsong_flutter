# 友人对战

> [!CAUTION]
> 由于落雪开发者Token限制，此功能会将您的成绩上传至作者的数据库，使用前需要您手动同意

![](image/屏幕截图%202026-08-19%20185346.png)

初次进入界面会弹出授权界面，点击**允许**即代表您同意将您的成绩上传至作者的数据库，点击**拒绝**则会退出此功能。  
***使用过程中产生的风险由您自行承担***  
> ~~依旧从ChiffonMai抄的界面~~

在上方输入框输入对方的好友码，点击**开始对比**即可开始对比。   
## 显示操作 
- 点击结果可以进入歌曲详情页  
- 点击难度可以查看各个难度下的对比结果
## 隐藏操作
- 点击**胜**即可仅查看胜利的曲目
- 点击**平**即可仅查看平手的曲目
- 点击**输**即可仅查看失败的曲目
- 点击**Rating**即可重置状态
