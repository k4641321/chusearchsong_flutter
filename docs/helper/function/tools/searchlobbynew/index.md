> 本功能基于Nearcade公开API编写
## 搜索
输入关键字会自动搜索，你也可以点击右边的搜索图标  
可以是**省份**+**城市**+**街道**，也可以是**店铺名称**，还可以是**Nearcade ID**  
  
点击搜索结果的**导航箭头**图标可以快速定位到机厅位置  
可以点击**漏斗**图标筛选游戏类型，选择完毕后要点搜索按钮才会生效  
点击地图上的图标可以查看机厅的详情  
点击右下角的定位图标可以移动到当前位置
### 机厅详情
机厅详情页显示以下内容：
- nearcade Id
- 店铺名称
- 店铺地址（长按即可复制地址
- 收录机种
  - 游戏名称
  - 版本
  - 币数
- 介绍
- 上传时间
- 更新时间
  
点击浮动按钮可以打开地图搜索  
可以在**关于** - **设置** - **地图设置** 选择启动哪个地图
