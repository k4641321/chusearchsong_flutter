# 随机歌曲
![随机歌曲](./image/屏幕截图%202026-08-19%20181732.png)
点击按钮即可选择 抽一首，抽三首，抽X首（需在下面输入框里输入数字）  
> 欸不是，怎么多了个搜索按钮，后面会删的）

## 随机范围
从搜索界面扒过来的筛选部分，可以自由组合进行抽取歌曲  
没有限制，所以能抽到世界末日的歌曲，还能抽到两首或者更多一模一样的曲子
  
点击结果即可进入歌曲详情页
