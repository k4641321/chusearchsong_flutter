# 歌曲推荐
> [!WARNING]
> 此工具配合落雪Token使用更佳

![pic](image/屏幕截图%202026-08-19%20181826.png)
如果你已经配置好落雪Token，进入工具界面会自动获取B50里最低Rating，你也可以手动输入最低Rating  
除了基础的歌曲筛选以外，还支持根据**预吃分数**进行筛选  
  
点击右上角漏斗按钮可以隐藏筛选，只保留搜索框和计算按钮
> [!CAUTION]
> 这里预吃分数并不是实际能提高的Rating，而是新歌的单曲Rating与最低单曲Rating的差值

点击可以进入歌曲详情页  
底部可以前后翻页，中间的页码可以更改跳转指定页码
