# B50生成
> [!WARNING]
> 使用前请配置好落雪Token，生成期间请保证网络通畅，存在本地的图片只有背景，评级与通关状态，其余信息一律都是网络获取，然后在本地画的

![B50生成](./image/屏幕截图%202026-08-22%20180858.png)
> 2026-07-19 已更新渲染方式，感谢[@ChiffonOwO](https://github.com/ChiffonOwO/ChiffonMai)提供的方案

首先选择要生成的类型，可选类型有：**标准B50，随机B50，AJ30，FC30**  
点击按钮生成B50，点击**保存B50**会根据不同平台选择不同方式  
Windows平台是直接选择地方保存，其余平台则调用系统分享
