## 搜索
输入关键字会自动搜索，你也可以点击右边的搜索图标  
支持按省份进行筛选搜索
## 隐藏操作
点击结果，会自动跳转地图软件进行搜索，目前支持的有：
- 高德地图
- 百度地图
可以在**关于** - **设置** - **地图设置** 选择启动哪个地图
