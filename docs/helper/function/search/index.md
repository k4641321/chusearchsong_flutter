# 最重要的功能——搜索
![搜索界面](image/屏幕截图%202026-07-29%20153320.png)
目前搜索功能支持一下关键词搜索：  
标题，曲师，别名，落雪id,谱师
## 筛选
软件对多种需求都尽量满足了，你可以按**流派，版本，难度，bpm，游玩状态（需要落雪token设置好）分别筛选**  
你也可以**多者结合起来筛选**，比如：  
流派+版本  
流派+版本+难度  
流派流派+版本+难度+bpm  
流派流派+版本+难度+bpm+游玩状态  
流派流派+版本+难度+bpm+游玩状态+关键词  
*以及更多结合...*
## 搜索结果展示
![搜索结果展示](image/屏幕截图%202026-07-29%20153246.png)
搜索结果会以这样的结果显示：  
***曲绘 落雪id - 曲名  流派 - 版本 \n 难度***  
点击结果即可进入歌曲详情页  
点击右下角浮动按钮可以回到顶部
