# 最重要的功能——搜索
![搜索界面](image/屏幕截图%202026-08-01%20125812.png)
目前搜索功能支持一下关键词搜索：  
标题，曲师，别名，落雪id,谱师
## 筛选
软件对多种需求都尽量满足了，你可以按**流派，版本，难度，bpm，游玩状态（需要落雪token设置好）分别筛选**  
你也可以**多者结合起来筛选**，比如：  
流派+版本  
流派+版本+难度  
流派流派+版本+难度+bpm  
流派流派+版本+难度+bpm+游玩状态  
流派流派+版本+难度+bpm+游玩状态+关键词  
*以及更多结合...*
## 特殊筛选
有人说可以加一个音符筛选，那我就加一下吧）  
使用特殊筛选，请先选择 ***启用特殊筛选***  
> [!WARNING]
> 该筛选方式需要配合最新最热歌曲数据使用，请确保你已经获取过最新最热歌曲数据

~~遥遥领先，优势在我~~

语法如下：
* $notetype 参数1 
* $notetype 参数1 参数2
* $notetype 参数1 参数2|$notetype 参数1 参数2

其中**$total**可以是total、tap、hold、slide、air、flick  
只输入参数1为筛选相等的音符数量  
输入参数1与参数2为 参数1~参数2的范围  
第三种语法是支持多种音符组合筛选  

例如：  
`$total 2725 2727`
![pic1](image/屏幕截图%202026-08-19%20175820.png)

又例如：  
`$tap 1567 1569|$hold 187`
![](image/屏幕截图%202026-08-19%20175913.png)

![搜索结果展示](image/屏幕截图%202026-08-19%20175757.png)
搜索结果会以这样的结果显示：  
***曲绘 落雪id - 曲名  流派 - 版本 \n 难度***  
点击结果即可进入歌曲详情页  
点击右下角浮动按钮可以回到顶部
