# 收藏
> 喜欢的歌曲，想推分的歌曲，肯定要好好留住啦

![收藏界面](image/屏幕截图%202026-08-19%20180536.png)
在歌曲详情页收藏之后，收藏的歌曲会在这里显示  
歌曲排序按收藏先后排序的
> 因为代码是这样写的  
> 读取收藏文件为Map，添加，写回去）

收藏的歌曲查看时同样会这样渲染：  
搜索结果会以这样的结果显示：  
***落雪id - 曲名  流派 - 版本 \n 难度***  
  
点击歌曲即可进入歌曲详情页  
## 导入与导出
### 导入
点击导入按钮，软件会让你选择一个json文件，**该操作会覆盖之前的收藏**
### 导出
点击导出按钮，软件会让你选择一个位置保存收藏文件，保存完成后，你可以把你的收藏文件分享给别人，也可以作为自己的收藏备份
