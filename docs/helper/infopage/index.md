# 关于界面
![](image/屏幕截图%202026-09-04%20204135.png)
三个图标按钮的功能（从左到右）分别是：  
- 前往Github地址
- 加入QQ群
- 前往帮助文档
  
## 设置界面
![](image/屏幕截图%202026-09-04%20204207.png)
你可以在此页面设置以下东西：  
- 翻译所需要用到的**SecretId**，**SecretKe**y，**ProjectId**
- 落雪Token（落雪个人API密钥）
- 谱面预览加速加载
- 启动时检查更新
- 主题模式
- 首选地图设置（用于机厅搜索，新旧都是

## 检查更新
点击按钮可以检查当前是否为最新版本  
  
## 感谢名单
点击可以查看为软件开发提供帮助的用户  
  
## 赞助作者
点击可以进入赞助页选择一种方式赞助作者，支持以下几种：  
- 微信支付（微信赞赏码
- 爱发电（抽的有点多，我更喜欢你微信直接给我
还有赞助排行榜可以查看，记得冲榜哦~  
  
## 更新日志与公告
点击进入查看更新日志，右上角按钮点击切换查看公告  
  
## 更新数据
点击后会弹出选择框，选择一项以进行数据更新：
- 所有数据
- 仅成绩
- 仅机厅数据（新）
- 仅基础数据
- 仅最新最热数据
