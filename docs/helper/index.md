# chusearchosng(中二查歌)
## 这是什么？
这是作者在使用了Python toga，Python Kivy后，迫不得以转为Flutter写的一个关于**中二节奏**的工具
> [!WARNING]
> 我并不是专业的，只是业余兴趣，边学边写，目前是使用AI进行辅助开发，**有答辩代码是非常正常的**

- [x] 基本查歌
- [x] 分类查歌
- [x] 版本查歌
- [x] 别名查歌
- [x] 曲师查歌
- [x] 定数筛选

- [x] 曲绘预览
