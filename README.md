# 中二查歌

一个使用flutter框架写的查歌软件，歌曲数据来源于落雪咖啡屋，目前为方便调试，歌曲数据是保存在本地，未来开发差不多时会换成联网获取

# 功能
- [x] 基本查歌
- [x] 分类查歌
- [x] 版本查歌
- [x] 别名查歌
- [x] 定数筛选
- [ ] id查歌(但落雪的id好像不是官方曲目id,考虑一下)
- [x] 歌曲详情
- [x] 曲绘预览
- [ ] 收藏夹
- [ ] 歌曲试听
- [ ] 多个收藏夹
- [ ] 工具
