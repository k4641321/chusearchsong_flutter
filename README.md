# 中二查歌

一个使用flutter框架写的中二节奏查歌软件，歌曲数据来源于落雪咖啡屋，初次启动会下载数据保存在本地，可以离线使用

# 功能
- [x] 基本查歌
- [x] 分类查歌
- [x] 版本查歌
- [x] 别名查歌
- [x] 曲师查歌
- [x] 定数筛选
- [x] 歌曲详情
- [x] 曲绘预览
- [x] 收藏夹
- [x] 歌曲试听
- [x] 工具
- [x] 店铺查询
- [ ] 成绩更新
